# Vietnam dashboard (Claude Dashboard artifact) — page source

Copy of the page files published as a Dashboard artifact (documents `files/index.html`, `files/app.js`, `files/gdp.js` and `files/export.js` in the artifact's database). `index.html` is assembled by `build.sh` from style.css, body.html and jg.js (as for dashboards/tw); `app.js` holds the Inflation charts and `gdp.js` the GDP tab (both only select and reshape published figures). Datasets point at uploaded copies of `data/vn/cpi/vn_cpi_dash.csv`, `vn_cpi_latest.csv`, `vn_cpi_regions.csv`, `vn_cpi_weights.csv` and `data/vn/ppi/vn_ppi_dash.csv` (inflation), and `data/vn/gdp/vn_gdp_dash.csv`, `vn_iip_dash.csv`, `vn_gdp_annual.csv`, `vn_gdp_intl.csv` (GDP; datasets `vn_gdp`, `vn_iip`, `vn_gdp_annual`, `vn_gdp_intl`). The artifact is the live copy; this folder is a backup.

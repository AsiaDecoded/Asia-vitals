# India dashboard (Claude Dashboard artifact) — page source

Copy of the page files published to https://claude.ai/artifact/5br5ud715W2635wrPTWrrd (documents `files/index.html` and `files/app.js` in the artifact's database). `index.html` is the published page (style.css + body.html + jg.js inlined by `build.sh`); `app.js` holds the inflation and financial calcs and charts; `gdp.js` (files/gdp.js) the GDP tab, charts 1-6; `datasets/` holds the dataset documents, which point at the uploaded data files. The data comes from `data/in/...` via the daily scheduled task. The artifact is the live copy; this folder is a backup, refreshed when the page changes.

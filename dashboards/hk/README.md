# Hong Kong dashboard (Claude Dashboard artifact) — page source

Copy of the page files published to https://claude.ai/artifact/2vqSwgK2mngF2xTtpykU48 (documents `files/index.html`, `files/app.js` and `files/export.js` in the artifact's database). `index.html` is built by `build.sh` from style.css, body.html and jg.js; `app.js` draws the charts and only picks and reshapes published rows (nothing is calculated); `datasets/` holds the dataset documents, which point at the uploaded data files from `data/hk/cpi/` and `data/hk/ppi/`. The artifact is the live copy; this folder is a backup.
